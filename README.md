## Featured Projects

### [RentNest](REPO_LINK)
A full-stack rental marketplace. The data model is built around a request entity that drives the full lease lifecycle (`Pending → Approved → Active → Completed`), with Stripe payments and a modular Prisma schema. Deployed on Vercel.

`TypeScript` `Express` `Prisma` `PostgreSQL` `Next.js` `Stripe`

### [Aegis](REPO_LINK)
An AI financial advisor built on a layered mediation architecture. Every request and response passes through independent layers that check user intent, enforce financial-safety rules and validate the agent's output, so the advice stays safe and auditable.
