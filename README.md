## About Me

I'm a Computer Science and Engineering student at AIUB (graduating 2027) who builds backend systems with TypeScript and Node.js.
My work centers on REST APIs, relational data modeling and payment integrations (Stripe, bKash, SSLCommerz).
I care about code that stays reliable and easy to change as a system grows, not just code that works today.

## Currently

- 🤖 Building **Aegis**, an AI financial advisor with a layered guardrail architecture
- 📚 Studying system design and backend internals (databases, OS, networking)

## Featured Projects

**[RentNest](REPO_LINK)**: a full-stack rental marketplace whose data model is built around a request entity that drives the full lease lifecycle (`Pending → Approved → Active → Completed`), with Stripe payments and a modular Prisma schema. Deployed on Vercel.
`TypeScript` `Express` `Prisma` `PostgreSQL` `Next.js` `Stripe`

**[Aegis](REPO_LINK)**: an AI financial advisor built on a layered mediation architecture. Every request and response passes through independent layers that check user intent, enforce financial-safety rules and validate the agent's output.
